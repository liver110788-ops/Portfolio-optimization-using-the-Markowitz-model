Постановка задачі

Задача дослідження полягає в тому, щоб на основі історичних ринкових даних по 12 активах сформувати та проаналізувати інвестиційний портфель за моделлю Марковіца, визначити структуру портфеля з найкращим співвідношенням дохідності та ризику, а також побудувати ефективну межу.

Для вирішення задачі використовуються реальні дані про ціни закриття акцій за період з 01.01.2016 по 01.01.2026.

Як активи обрано 12 інструментів великих компаній: AAPL, MSFT, GOOGL, AMZN, NVDA, META, TSLA, JPM, XOM, KO, GLD, BTC-USD.

На основі історичних цін необхідно:

розрахувати дохідності для кожного активу;
визначити середню очікувану дохідність активів;
побудувати коваріаційну матрицю дохідностей;
розрахувати ризик та очікувану дохідність різних комбінацій активів;
знайти:
портфель мінімального ризику;
портфель максимальної дохідності;
портфель максимальної дохідності при заданому рівні ризику;
портфель з максимальним коефіцієнтом Шарпа;
побудувати ефективну межу Марковіца;
порівняти отримані портфелі та зробити висновок щодо найбільш раціональної структури інвестицій.
Чому я обрав саме цей проєкт

Цей проєкт демонструє, як на основі сирих фінансових даних можна отримати аналітичні висновки та практичні рекомендації.

Із використанням методів кількісного аналізу та оптимізації будується модель, що дозволяє приймати обґрунтовані інвестиційні рішення.

Модель Марковіца допомагає збалансувати ризик і дохідність, визначити оптимальну структуру портфеля та підвищити ефективність управління інвестиціями.

Подібні підходи широко застосовуються в управлінні активами, ризик-менеджменті та фінансовому плануванні, дозволяючи покращувати якість управлінських рішень і підвищувати ефективність бізнесу.
